# TUSMindSpace
## Advanced Mobile Application Development: Final Project

Student: Deepu Dinesh (K00290679)

TUSMindSpace is a proposed application for Android devices, that helps TUS students
build towards daily habits for stress management through short, guided meditations,
journaling and quick access to real support when they need it.

## Features
| Feature | Status |
|---|---|
| Bottom navigation between 5 screens (Jetpack Compose Navigation) | Done |
| Home screen with streak, quick actions, quote, affirmations | UI completed |
| Meditations with session timer | WIP |
| Mood journal (Room) | Planned |
| Resources map (Google Maps) |  Planned |
| Contact Us with tap-to-call | Planned |
| Daily reminder notification | Planned |
| Phone and tablet, portrait and landscape layouts | Planned |

## Setup & build
**Requirements:** Android Studio Quail 3 | 2026.1.3 Canary 1, Android SDK, emulator or
device running Android 8.0 (API 26)+.

1. Clone the repo:
   ```https://github.com/MAD2IK/TUSMindSpace.git```
2. Open the folder in Android Studio and wait for Gradle sync to finish.
3. Select an emulator or connected device and press **Run**.
